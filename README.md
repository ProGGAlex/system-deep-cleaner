# 🧹 System Temp Files & Deep Cleaner

A lightweight, fast, and transparent batch script (`.bat`) designed for Windows to clean up system junk, temporary files, browser/shader caches, and update leftovers without installing heavy third-party software.

---

### 🇺🇸 English Documentation

#### What does this script do?
Over time, Windows accumulates gigabytes of unnecessary data that wastes disk space and can occasionally slow down the system. This script automates the cleanup of the most common junk directories safely and efficiently.

#### Detailed Breakdown of Cleaned Locations:
1. **User TEMP (`%TEMP%`)**
   * *What it is:* Temporary files created by active user applications and games.
   * *Why it's removed:* Apps often forget to delete their temp files after closing, leading to hidden gigabytes of waste.
2. **System Temp (`C:\Windows\Temp`)**
   * *What it is:* Temporary files generated by Windows system processes and installers.
   * *Why it's removed:* Safe to delete; frees up core system partition space.
3. **Windows Prefetch (`C:\Windows\Prefetch`)**
   * *What it is:* Data used by Windows to speed up application launch times.
   * *Why it's removed:* Clearing it forces Windows to rebuild fresh, optimized prefetch data, fixing minor launch lags.
4. **DirectX Shader Cache (`$LOCALAPPDATA\D3DSCache`)**
   * *What it is:* Precompiled GPU shaders cached by games and graphics drivers to reduce stuttering.
   * *Why it's removed:* Over time, old shader caches can bloat or get corrupted, causing micro-stutters in games. Clearing them forces the driver to rebuild a clean cache.
5. **Windows Update Downloads (`C:\Windows\SoftwareDistribution\Download`)**
   * *What it is:* Installation files left over after Windows downloads and installs system updates.
   * *Why it's removed:* Windows keeps these installation packages forever "just in case," wasting massive amounts of space. *Note: The script temporarily stops the Windows Update service (`wuauserv`) to safely clear these locked files.*
6. **Windows Cleanmgr (Disk Cleanup)**
   * *What it is:* The built-in Windows utility that targets system error memory dumps and old installation logs.
   * *Why it's removed:* Deep system-level maintenance.
7. **Recycle Bin**
   * *What it is:* Deleted files waiting to be permanently erased.
   * *Why it's removed:* Finalizes the cleanup so you don't have to empty it manually.

#### Features
* **Automatic Administrator Privileges:** Automatically requests elevation (Run as Admin) if launched without it.
* **Smart Space Counter:** Calculates and displays the exact amount of junk freed in Megabytes after completion.
* **No Bloatware:** Written in native Windows Batch and PowerShell commands—no background processes, no telemetry, no GUI overhead.

### 🇷🇺 Русская документация

#### Что делает этот скрипт?
Со временем Windows обрастает гигабайтами мусора, который забивает диск и может вызывать микрофризы. Этот скрипт автоматизирует очистку основных временных директорий быстро, безопасно и без установки тяжелых сторонних программ.

#### Подробный разбор того, что и зачем удаляется:
1. **Временные файлы пользователя (`%TEMP%`)**
   * *Что это:* Мусор от запущенных программ и игр.
   * *Зачем удаляется:* Софт часто забывает стирать за собой временные файлы при закрытии, из-за чего со временем накапливаются гигабайты хлама.
2. **Системный Temp (`C:\Windows\Temp`)**
   * *Что это:* Временные файлы системных служб и установщиков Windows.
   * *Зачем удаляется:* Безопасно очищается для высвобождения места на системном диске.
3. **Кэш Prefetch (`C:\Windows\Prefetch`)**
   * *Что это:* Данные, которые Windows использует для ускорения запуска приложений.
   * *Зачем удаляется:* Очистка заставляет систему пересоздать свежий и актуальный кэш, что помогает избавиться от мелких багов при запуске программ.
4. **Кэш шейдеров DirectX (`$LOCALAPPDATA\D3DSCache`)**
   * *Что это:* Скомпилированные видеокартой шейдеры из игр для уменьшения лагов.
   * *Зачем удаляется:* Старый кэш со временем раздувается или может повредиться, вызывая подлагивания в играх. Очистка заставляет драйвер пересобрать его заново.
5. **Загрузки обновлений Windows (`C:\Windows\SoftwareDistribution\Download`)**
   * *Что это:* Установочные архивы обновлений, которые система скачала, установила, но навсегда оставила лежать на диске «на всякий случай».
   * *Зачем удаляется:* Освобождает колоссальное количество места. *Примечание: Скрипт на секунду останавливает службу обновлений (`wuauserv`), чтобы файлы удалились без ошибок.*
6. **Встроенная очистка диска Cleanmgr**
   * *Что это:* Стандартная утилита Windows для удаления дампов памяти и старых логов.
   * *Зачем удаляется:* Глубокая системная гигиена.
7. **Корзина**
   * *Что это:* Удаленные файлы, ожидающие окончательного стирания.
   * *Зачем удаляется:* Чтобы не чистить её вручную.

#### Особенности
* **Авто-права администратора:** Если запустить просто так, скрипт сам перезапустится от имени администратора.
* **Подсчет удаленного мусора:** В конце работы скрипт через PowerShell считает разницу и пишет в консоль, сколько именно мегабайт мусора было успешно уничтожено.
* **Никакого мусора под капотом:** Написан на чистых средствах Windows (`.bat` + `PowerShell`). Никаких фоновых процессов, рекламы и слежки.
